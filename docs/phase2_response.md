## Honest limits
- Worlds are generated by our simulator; real-data checks so far are public messages (BTTC) and public statistics, not upay data.
- The user study tool is ready, but its results remain pending until real volunteers participate. It measures stated intentions, not observed behaviour.
- Fairness can be improved only by spending false pauses with the current signals; we show the trade-off rather than hide it.
- The scaled stack runs on one laptop (Docker); the Kubernetes manifests are a template for a cluster. Four scorer replicas did not improve throughput over two under the tested 32-client load on this machine.
- BTTC is a labelled message dataset, not verified upay fraud incidents. The local download contained 10,267 complete rows, 16 fewer than the 10,283 rows reported by its publisher. The real-label results are pilot retraining experiments; the served text model remains the synthetic-trained model.
